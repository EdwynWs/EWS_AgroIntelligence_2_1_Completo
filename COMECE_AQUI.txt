INSTALAÇÃO NOVA PARA DEMONSTRAÇÃO
1. Extraia o ZIP em uma pasta nova, sem apagar a instalação anterior.
2. No VS Code, abra a subpasta ews-agrointelligence, que contém package.json.
3. Abra o terminal nessa subpasta e execute UM comando por vez:

npm install -g pnpm@11.25.0
pnpm install --frozen-lockfile
Copy-Item .env.example .env
pnpm db:migrate
pnpm db:seed
pnpm dev

Pare ao primeiro erro. Requer Node.js 24.
Abra http://localhost:3000/login e clique em Explorar demonstração.

Se já possui dados reais: preserve .env e banco, faça backup e siga
o guia docs/INSTALACAO_2_1.md,
seção Atualizar instalação existente. Não execute seed em base real.
